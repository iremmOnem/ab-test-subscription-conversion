📊 A/B Test: Subscription Conversion Optimization

🎯 Project Overview

This project presents an end-to-end A/B testing analysis aimed at improving subscription conversion rates in a mobile application.
Users were offered a $4.99 weekly subscription after onboarding, and the goal was to evaluate whether changing the pricing message would impact conversion behavior.

🧪 Experiment Design

Group A (Control): Standard $4.99 subscription offer
Group B (Variant): Same offer framed as “50% discount”

📌 Key Idea

Both groups see the same price, but with different psychological framing.

📊 Dataset

Daily app installs: ~2000 users
34% reach subscription screen
Conversion tracked at user level (binary outcome)

📈 Metrics

Primary Metric:
Conversion rate (purchase / subscription screen view)

Supporting Metrics:
Funnel drop-off
Subscription screen engagement

🧠 Methodology

A/B test experimental design
Two-proportion Z-test for statistical significance
95% confidence intervals
Python (pandas, numpy, matplotlib)

📊 Visualizations

Conversion rate comparison (A vs B)
Conversion trend over time

📌 Key Findings

Pricing perception has a measurable impact on user behavior
“Discount framing” improves conversion performance
Results validated through statistical testing

🚀 Conclusion

This experiment demonstrates how small changes in messaging can significantly influence user decision-making. It highlights the importance of hypothesis-driven experimentation in product analytics.
